## 1. 개요 및 화면 목적

- **화면명**: 알트코인/비트코인 사이클 분석 및 예측 대시보드 (`ALT/BTC CYCLE ANALYZER`)
- **디폴트 타깃 환경**: **15인치 모니터/노트북 (1920×1080, 배율 125%~150% 기준)**
- **보조 타깃 환경**: **휴대폰 모바일 뷰포트 (`max-width: 768px`)**
- **목적**: 과거 사이클 정점(Peak) 기준 가격 데이터를 100% 정규화(Peak-Normalized)하여 일자별 경과에 따른 하락/상승 박스 구간(Box Zone), 서브 박스(Sub-Box), 시나리오 예측 경로를 다각도로 비교·분석한다.
- **주요 기술 스택**: React 18, TypeScript, Lightweight Charts v4.1.1, Supabase REST API.

## 4. 컴포넌트별 상세 인터랙션 사양

### 4.1 Header (상단 헤더)
- **15인치**: 타이틀과 메타 정보(`PEAK-NORMALIZED...`)를 좌우 분할 배치.
- **휴대폰**: 메타 텍스트를 숨기고, 우측에 `[≡ 코인 선택 (#N)]` 토글 버튼 배치하여 터치 시 드로어 오픈.

### 4.2 Sidebar (코인 탐색/선택)
- **15인치**: 좌측에 상시 노출. 너비 `260px`로 차트 캔버스 면적 극대화. 검색창 및 스크롤 리스트.
- **휴대폰**: 기본 화면에서는 숨김 처리. 드로어(바텀시트) 형태로 호출되어 화면의 85% 높이로 노출, 코인 선택 후 닫기.

### 4.3 Toolbar (차트 툴바)
- **15인치**: 사이클 토글 버튼 군 + 우측 `OPTIONS ▾` 드롭다운 메뉴.
- **휴대폰**: 가로 스크롤 가능한 칩 컨테이너(`overflow-x: auto`)로 터치 스와이프 지원.

### 4.4 Chart Area (차트 캔버스)
- **15인치**: 남은 화면 높이를 꽉 채우는 유연한 구조 (`flex: 1`, `min-height: 420px`). 마우스 호버 크로스헤어 및 플로팅 툴팁.
- **휴대폰**: 뷰포트 높이의 `50~60vh` 할당. 원터치 롱프레스 크로스헤어, 핀치 줌(두 손가락 확대/축소) 동작 지원.

### 4.5 Stats Bar (하단 요약 통계 바)
- **15인치**: 하단 가로 행 정렬 (`flex-direction: row`).
- **휴대폰**: 가로 스와이프 카드 UI (`overflow-x: auto; scroll-snap-type: x mandatory`).
